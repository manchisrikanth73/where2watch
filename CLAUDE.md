## Project Overview

**where2watch** is a platform to help users find where to watch their favorite movies and TV shows. The repository is in early initialization — no build tooling, dependencies, or source code have been added yet.

## Branch Conventions

- `master` — production-ready code
- `test` — pre-production testing
- `dev` — active development

All development should target the `dev` branch. Changes flow: `dev` → `test` → `master`.
